# Аналитика промо и переходов

Счётчик пока не установлен. На сайте нет подключённой Яндекс Метрики, Google Analytics или Umami; этот документ описывает следующий шаг, а не уже работающий сбор статистики.

## Что измерять

Для задачи «дали промо → зашли на сайт» достаточно отчёта по визитам и посетителям в разрезе конкретного промо. Просмотры страниц — отдельная метрика: за один визит человек может открыть несколько разделов.

Показы рекламного сообщения и расходы берутся из статистики площадки или рекламного кабинета. Сайт самостоятельно не знает, сколько людей увидело сообщение. Стоимость визита можно считать как расходы на размещение / визиты из этого размещения. Клики по ссылке в рекламном кабинете и визиты в счётчике не обязаны совпадать, например, если человек закрыл страницу до загрузки счётчика.

## Варианты

| Подход | Для чего подходит |
| --- | --- |
| Яндекс Метрика + UTM | Практичный старт: посещения по источникам и отдельным промо, готовые отчёты |
| Umami + UTM | Альтернатива; при самостоятельном размещении потребуются отдельное приложение аналитики и его хранилище |
| Серверные access-логи | Технические запросы и диагностика; без дополнительной обработки это не готовый маркетинговый отчёт |

Для первого этапа достаточно Яндекс Метрики без Вебвизора. Карты поведения, запись сессий, сложные цели и интеграция с CRM для подсчёта переходов не нужны.

## Как подключить Яндекс Метрику

1. Выберите публичный адрес сайта. Текущая версия в Sites закрыта входом через ChatGPT; для реального промо нужен публичный доступ или собственный домен на VPS.
2. В аккаунте Яндекс Метрики создайте счётчик для этого адреса. Сохраните его числовой ID и официальный код установки. ID счётчика не является паролем; доступ к аккаунту передавать разработчику не нужно.
3. В коде сайта подключите один общий клиентский компонент через `app/layout.tsx`, загрузив официальный скрипт через `next/script` после начала отображения страницы.
4. Учтите навигацию App Router: переходы Next.js между разделами могут проходить без полной перезагрузки. Следуйте официальной SPA-инструкции Метрики: `defer: true` при инициализации, затем один `hit` на первоначальный показ и каждую смену страницы. Не отправляйте первоначальный просмотр одновременно автоматически и вручную. При первом показе передавайте полный адрес с UTM-параметрами.
5. Отправку просмотров не включайте для `/edit/` и служебных API. Учтите уже открытые вкладки редактора и переход из публичной части: служебные действия не должны попадать в маркетинговую статистику.
6. Пересоберите и разместите сайт. Проверьте счётчик и переход с тестовой UTM-ссылкой; затем откройте отчёт «Источники → Метки UTM».
7. Обновите страницы о данных и cookies: нынешняя формулировка об отсутствии аналитики после установки счётчика станет неверной. Конкретный текст должен соответствовать выбранным настройкам и режиму использования.

Этот репозиторий пока не содержит активного tracking-компонента: для подключения сначала нужен выбранный счётчик и публичный адрес.

## Ссылки для каждого промо

Пример, где `example.com` нужно заменить своим доменом:

```text
https://example.com/?utm_source=telegram&utm_medium=social&utm_campaign=solo_pr_launch&utm_content=post_01
```

- `utm_source=telegram` — откуда переход.
- `utm_medium=social` — тип канала; для рекламных размещений можно последовательно использовать `paid_social`, для рассылки — `email`.
- `utm_campaign=solo_pr_launch` — общая кампания.
- `utm_content=post_01` — конкретный пост или вариант объявления.

Следующему посту присвойте `post_02`, следующей рассылке — другое значение. Для сравнения отдельных Telegram-каналов можно указывать название канала в `utm_content`, сохраняя источник `telegram`. Используйте единые названия латиницей без пробелов. Не помещайте в UTM имена людей, email и другую персональную информацию.

Важно сохранять метки в первом адресе, на который попадает посетитель, и не терять их при редиректах. Сам по себе параметр UTM ничего не считает: его обрабатывает установленный счётчик.

## Результат первого этапа

Отчёт: дата → источник → кампания → конкретное промо → визиты → посетители. При добавлении расходов — стоимость визита.

Позже можно отдельно считать нажатие на почту или переход в Соло-PR. Нажатие на mailto — это клик, а не подтверждение отправки письма.
